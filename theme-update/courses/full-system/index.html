Đang dùng gì và để làm gì?

  • `node -v`: hỏi Node đang cài phiên bản nào; không chạy project, chỉ kiểm tra runtime.
  • `npm -v`: kiểm tra package manager đi kèm Node.
  • `git --version`: xác nhận máy có Git.
  • `docker --version`: kiểm tra Docker CLI.
  • `mkdir/cd`: tạo và đi vào workspace.
  • `git init`: biến folder thành Git repository bằng cách tạo thư mục ẩn `.git`.

Quy trình chạy

  1. Terminal nhận lệnh
  2. Hệ điều hành tìm executable tương ứng trong PATH
  3. Executable chạy và in phiên bản hoặc tạo cấu trúc
  4. Nếu lệnh không tồn tại → lỗi command not found / not recognized

Kết quả nên ra

  • Node nên là dòng LTS hiện hành; khóa dùng Node 24 LTS.
  • Git và Docker trả về số phiên bản, không báo lỗi.
  • Sau `git init`, `git status` chạy được.

Lỗi dễ gặp

  • Cài Node nhưng terminal cũ chưa reload PATH.
  • Chạy lệnh ở sai folder.
  • Dùng Node Current thay vì LTS rồi gặp khác biệt dependency.

  const res = await fetch(`${process.env.NEXT_PUBLIC_API_URL}${path}`, init);
  if (!res.ok) {

4. Code / mẫu kỹ thuật

Đang dùng gì và để làm gì?

Quy trình chạy

  2. Insert user
  3. Insert relationship
  4. Success → COMMIT
  5. Failure → ROLLBACK

  • Không hiểu N+1 query.
