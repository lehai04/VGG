# Thư mục ảnh cho từng nhóm trang

Bạn tải ảnh vào đúng thư mục bên dưới. Nên dùng tên file không dấu, chữ thường, phân cách bằng dấu gạch ngang.

## Home

- `home/banner/banner-01.jpg`: banner Hero thứ nhất, khuyến nghị 1920 × 1080 px.
- `home/banner/banner-02.jpg`: banner Hero thứ hai, khuyến nghị 1920 × 1080 px.
- `home/sections/`: ảnh cho các khối nội dung khác trên trang chủ.

## Các nhóm trang

- `discover/`: Khám phá VGG, giới thiệu, tầm nhìn, lãnh đạo, xếp hạng.
- `programmes/`: chương trình đào tạo, Thạc sĩ, Tiến sĩ và từng ngành.
- `admissions/`: tuyển sinh, học phí, học bổng, nộp hồ sơ, mốc thời gian.
- `research/`: nghiên cứu, dự án, công bố và hội thảo.
- `global/`: hợp tác quốc tế, trao đổi và chương trình liên kết.
- `student-success/`: câu chuyện và thành tựu người học.
- `news/`: tin tức và sự kiện.
- `resources/`: tài nguyên, biểu mẫu và tài liệu.
- `shared/`: ảnh dùng chung ở nhiều trang.

Trong mỗi nhóm, dùng thư mục `hero/` cho ảnh đầu trang và `content/` cho ảnh nội dung. Ví dụ:

`admissions/hero/hoc-bong.jpg`

`admissions/content/hoc-bong-tai-nang.jpg`

## Các ảnh mẫu hiện đang được website sử dụng

Mình đã đặt bản sao các ảnh đang hiển thị vào từng thư mục `content/` và đã nối code sang các file này. Bạn có thể thay trực tiếp, nhưng cần **giữ nguyên tên file và phần mở rộng**:

- `campus.jpg`: ảnh toàn cảnh khuôn viên, thường dùng cho hero, nền và khối “Khám phá thêm”.
- `graduates.jpg`: ảnh học viên/tốt nghiệp, thường dùng cho card và khối nội dung.
- `academic-leader.avif`: ảnh nhân sự học thuật, lãnh đạo hoặc chuyên gia.
- `celebration.jpg`: ảnh sự kiện/chúc mừng tốt nghiệp.

Ví dụ muốn đổi ảnh khuôn viên riêng của trang Tuyển sinh, thay file:

`admissions/content/campus.jpg`

Muốn đổi ảnh tương tự nhưng chỉ ở trang Khám phá VGG, thay file:

`discover/content/campus.jpg`

Các ảnh Hero lấy trực tiếp từ Unsplash trong dữ liệu cũ vẫn được giữ nguyên đường dẫn online. Khi có ảnh Hero riêng, hãy tải vào thư mục `hero/` của nhóm trang và báo tên file để mình thay đường dẫn.

Định dạng ưu tiên: WebP hoặc JPG; dung lượng nên dưới 700 KB/ảnh. Sau khi tải ảnh xong, gửi mình danh sách tên file để mình điền vào đúng vị trí.
